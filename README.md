# 🛒 Proyecto Final React - eCommerce

Este es un proyecto de eCommerce desarrollado en **React** como parte del curso de desarrollo frontend. El sitio permite navegar por una tienda online simulada, visualizar productos, ver detalles, añadirlos al carrito y finalizar una compra.

## 🚀 Tecnologías utilizadas

- React
- React Router DOM
- Context API
- Firebase (Firestore)
- Vite
- CSS / Estilos personalizados

## 📦 Funcionalidades principales

- Navegación entre páginas con React Router.
- Listado de productos.
- Detalle individual de productos.
- Sistema de carrito con contexto global.
- Formulario de checkout con validación.
- Generación de orden de compra almacenada en Firebase Firestore.
- Página de contacto.
- Página de error 404.
